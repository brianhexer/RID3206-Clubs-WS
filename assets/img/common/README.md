## Image Requirements

- All images should be in JPG format (.jpg)
- Recommended image sizes:
  - About background (01.jpg): 1200x600px or wider
  - Sponsor logos (L*.jpg): 400x200px
  - Event images (event-*.jpg): 600x400px
  - Member photos (P*.jpg): 400x500px
  - Testimonial avatars (T*.jpg): 200x200px
  - Gallery images (PR*.jpg): 800x600px

## Upload Instructions

1. Add your images to this `/assets/img/common/` folder
2. Name them according to the convention above
3. The site will automatically display them in their designated sections
